使用说明

          
不需要打开或登录 Edge / B 站 / 抖音 / 快手，所有抓取都在后台完成。


          
第一次使用

          
    
            
  1. 双击运行 TC002Desk.exe，确认左下角显示“转发运行中”。
    2. 
            
  2. 电脑和 TC002 连同一个局域网；首次运行防火墙提示请允许“专用网络”。
    3. 
            
  3. “设备概览”里点“连接”（默认 192.168.31.124:8080，也可搜索设备）。
    4. 
            
  4. “页面与显示”编辑页面；直播页填房间号；保存后设备热生效。
    5. 
            
  5. 设备切到直播页，或按旋钮按键立即刷新；平时按 live.refreshSec 自动刷新。
    6.

数据源

          
    
            
  • hybrid：B 站由设备直连，抖音/快手由本机转发（推荐）。
    • 
            
  • bridge：三个平台都由本机转发。
    • 
            
  • off：不取直播数据；push：由外部程序 POST /api/live 推送。
    • 
          


          
快手说明

          
    
            
  • 工具会自己启动隐藏的无头 Edge，不读取你浏览器里的登录状态。
    • 
            
  • 第一次请求约 3–10 秒，可能先显示 -- 或 timeout，下一次轮询就有数据。
    • 
            
  • 平台按 IP 限流时会返回 rate_limited，请等几分钟或减少快手房间数；登录不能绕过。
    • 
          


          
常见问题

          
    
            
  • 设备显示 --：检查转发是否运行、设备 live.url 是否为本机局域网地址、防火墙是否放行 8081。
    • 
            
  • 连接失败：确认设备 IP（路由器 DHCP 可能变化），或用“搜索设备”；SoftAP 配网默认 192.168.100.1。
    • 
            
  • 切换后 IP 变了：WiFi 保存后设备会重连，重新搜索/连接即可。
    • 
            
  • 关闭软件：转发会停止；需要常驻请保持窗口运行，或把 exe 放进启动项。
    • 
            
  • 快手 rate_limited：平台限流，不是设备故障；降低刷新频率或房间数。
    • 
          


          
安全

          
只监听局域网，不要把 8081 映射到公网；不需要账号，不落盘任何 cookie。
